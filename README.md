# KAI — laboratorio iPhone

Prototipo de interfaz móvil de KAI. No es un modelo 3D ni un bot conectado a Kick.

## Publicar con GitHub Pages

1. Abrir Settings → Pages en este repositorio.
2. En Build and deployment elegir Deploy from a branch.
3. Elegir main y /(root), y guardar.
4. Esperar el despliegue y abrir https://borderdev19.github.io/kai-avatar/ en Safari.

## Pruebas

- Pulsar Ejecutar pruebas: debe mostrar JavaScript ejecutándose: OK.
- Pulsar Simular espectador: debe aparecer un mensaje y una respuesta.
- Pulsar Probar voz: escuchar audio si Safari ofrece síntesis en español.
- Pulsar Silenciar voz y verificar que no haya reproducción.

El resultado de la prueba de voz depende de Safari y debe verificarse en el dispositivo.

## Seguridad

No introducir tokens, claves de Kick ni claves de ElevenLabs en esta página pública. Las futuras integraciones se implementarán con un backend seguro.
